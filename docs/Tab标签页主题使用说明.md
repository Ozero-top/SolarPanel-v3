# Tab标签页主题使用说明

Tab标签页（内部标识 `wetab`）是仿浏览器新标签页的桌面式主题：壁纸为主视觉，分组与卡片去掉底色，只保留图标与标题，左侧悬浮分组条、底部 Dock 常用栏，适合大屏导航页。

## 一、启用主题

1. 进入后台「站点设置 → 外观与卡片 → 风格主题」，选择 **Tab标签页**，保存。
2. 主页刷新后即时生效，无需重启服务。
3. 建议同时把「卡片样式」设为 **导航栏** 或 **导航栏·应用**；Tab标签页的左侧分组条、滚轮切组、Dock 都基于导航栏模式工作。
4. 深浅模式仍由访客在主页右上角按钮自行切换，不影响主题本身。

## 二、主页布局

- 顶部：站点标题、时钟、日期、天气（同一行居中）。
- 中部：搜索框（搜索 / 热点新闻切换）、分组图标网格。
- 底部：Dock 常用栏（有固定卡片时才显示）。
- 默认不显示页脚与「返回顶部」按钮。

## 三、左侧分组导航

- 默认收起，只在左侧中间保留一个 ≡ 悬浮把手。
- **鼠标悬停 ≡ 即自动浮出导航条**，移入导航条保持展开；指针移开约 0.4 秒自动收起。
- 悬停时导航条为 48px 窄条：图标带圆角底框、分组名在条外右侧；选中项图标底框高亮为淡紫。
- 点击分组即跳转到对应分组卡片区。
- 点击空白处、选中分组后、按 `Esc` 都会收起。
- 触屏设备点按 ≡ 也可展开。
- 窗口宽度 ≤ 1024px 时左侧导航自动隐藏，改用移动端分组栏。

## 四、滚轮切换分组

- 页面任意位置（卡片、Dock、搜索框、空白处）滚动滚轮都可切换分组。
- 切换顺序为逐级推进：先在当前一级分组内逐个二级分组定位，走到最后一个后再切到下一个一级分组；反向同理（切到上一个一级分组的最后一个二级分组）。
- 滚轮切换时左侧导航条会自动浮出，约 2.6 秒后自动收起。
- 两个例外不触发切组：热点新闻视图内；弹窗/设置面板内部滚动时。

## 五、底部 Dock

- 仅管理员可固定：在任意卡片上右键，选择「📌 固定到 Dock」；再次右键可选「从 Dock 移除」。
- 固定的卡片保存在本机浏览器 localStorage（`sp_wetab_dock`），不写入站点设置，不同设备各自独立。
- Dock 显示三态（见下方界面设置）：显示 / 隐藏 / 自动隐藏；自动隐藏时鼠标移到底部会自动浮出。
- 可隐藏 Dock 标题；标题超长自动截断为前 8 个字符。

## 六、界面设置（左下角 ⚙）

点击主页左下角 ⚙ 打开面板，设置实时生效并保存在本机（`sp_wetab_prefs`）：

| 设置项 | 范围 | 说明 |
| --- | --- | --- |
| 图标上下间距 | 1–40 | 卡片行与行之间、分组之间留白 |
| 图标左右间距 | 1–40 | 图标网格列间距 |
| 图标大小 | 32–72 | 卡片图标与格子尺寸 |
| 内容宽度 | 800–2600 px | 主页卡片区域宽度与两侧留白；默认取后台「内容区域最大宽度」 |
| Dock 显示标题 | 开 / 关 | 关闭后 Dock 只显示图标 |
| Dock 显示 | 显示 / 隐藏 / 自动隐藏 | 自动隐藏时鼠标移到底部浮出 |
| Dock 背景 | 0–100 | 0 = 无背景框只剩图标；100 = 半透明磨砂玻璃；中间值按比例缩放底色、边框、阴影与模糊 |

其他按钮：

- **🖼 更换壁纸**：仅管理员可见。点击后居中弹窗，分「预置壁纸」「已上传壁纸」两组，可点选预置图、上传本地图片（10MB 内，自动转 WebP 存到 `uploads/wallpapers/`），或「恢复默认渐变」。
- **❓ 常见问题**：所有人可用，点击后居中悬浮小窗，再次点击按钮 / 点 X / 点空白 / `Esc` 返回导航页。
- **🛠 打开后台管理**：仅管理员与编辑者可见。

权限说明：访客与只读账号可以打开 ⚙ 面板查看，但滑杆、复选框、下拉框均为禁用状态；「更换壁纸」「打开后台管理」不显示。

## 七、壁纸与文字颜色

- 更换壁纸后，卡片标题、分组标题与描述、时钟、日期、天气文字会自动按壁纸亮度切换深色或浅色，并带对应投影，保证可读。
- 若后台开启了「每日壁纸」，每日壁纸优先于手动选择的壁纸；关闭后使用 ⚙ 中选择的壁纸。
- 未设置壁纸时使用主题自带的深色渐变底，文字为浅色。

## 八、相关后台设置

- 外观与卡片 → 内容区域最大宽度：作为「内容宽度」滑杆未调整时的默认值。
- 外观与卡片 → 卡片样式：请使用「导航栏」或「导航栏·应用」，否则左侧分组条与 Dock 不出现。
- 站点设置 → 访问控制：访客/只读账号只能查看界面设置面板，不能修改。

## 九、常见问题

- **左侧导航不出现**：确认主题为 Tab标签页、卡片样式为导航栏类，且窗口宽度大于 1024px。
- **Dock 看不到**：确认已右键固定至少一张卡片，且「Dock 显示」不是「隐藏」。
- **滚轮不切组**：确认当前不在热点新闻视图，且指针不在弹窗内部。
- **换了壁纸文字看不清**：确认壁纸已保存成功；跨域外链壁纸无法读取像素时，文字默认使用浅色。
- **设置保存后换设备失效**：界面设置与 Dock 固定均为本机偏好，需要在另一台设备上重新调整。
