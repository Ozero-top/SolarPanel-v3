# SolarPanel 剪藏扩展使用说明

适用版本：**1.0.9**（Chrome / Edge，Manifest V3）

把当前网页一键保存到自托管的 SolarPanel：生成导航卡片、保存正文快照与整页截图，并可在剪藏库中阅读、检索、收藏。扩展只读取当前页地址、标题与选中文本，标题、图标、封面、描述由你的服务器抓取。

---

## 一、安装

1. 从 GitHub Releases 下载 `solarpanel-clipper-v1.0.9.zip`（同目录 `SHA256SUMS.txt` 可校验）。
2. 解压到固定目录，例如 `D:\SolarPanel\clipper`，安装后不要移动或删除该目录。
3. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择解压出的目录。
5. 浏览器提示「开发者模式扩展」属于侧载（非商店安装）的正常现象。

支持 Chrome / Edge；Firefox 见第十节。

## 二、首次配置

打开扩展弹窗右上角「设置」（或首次打开时的「打开设置」按钮），填写：

| 配置项 | 说明 |
| --- | --- |
| 服务器地址 | 你的 SolarPanel 地址，如 `https://nav.example.com`、`http://192.168.1.10:10086`，不要带结尾 `/` |
| 个人访问令牌 | 在 SolarPanel 后台「剪藏与接入」生成的 `sp_...` Token，可随时吊销 |
| 默认分组 | 快速保存（快捷键 / 右键）时使用的分组；弹窗内仍可临时改选其他分组 |
| 快速保存快捷键 | 默认 `Alt+Shift+S`，可点击「修改快捷键」到浏览器快捷键页改绑 |

填写后点「测试连接」，显示已连接账号即配置成功；也可点「打开后台生成 Token」直达后台配置页。

Token 只保存在本机浏览器 `chrome.storage.local`，只在请求你自己的服务器时随请求发送。

## 三、保存当前页（弹窗）

点击工具栏图标打开弹窗，默认在「保存当前页」页签：

- **标题**：自动带入页面标题，可修改（最多 200 字）。
- **分组**：默认选中设置里的默认分组，可改为任意一级 / 二级分组。
- **截图方式**：
  - `整页（滚动拼接）`：自动滚动截取整页，拼接为一张长图；超长页面最多约 12000px，过大时自动转 JPEG；
  - `仅可视区`：只截当前屏幕；
  - `不截图`：只存卡片与正文。
- **标签（可选）**：用逗号、中文逗号或分号分隔，最多 20 个，可写 `#技术` 形式。
- **备注（可选）**：记录保存原因，最多 500 字。
- **同时保存正文快照**：默认勾选，服务端抓取正文供阅读页离线阅读与搜索；取消则只存卡片。

截图方式与「保存正文快照」会被记住，下次打开沿用上次选择。

点「保存到 SolarPanel」后：

- 保存成功：弹窗切换为完成态，可直接「在剪藏库查看」或「打开原文」；
- 重复链接：提示「该链接已存在」，可选择「更新已有卡片截图」或「仍要另存」；
- 网络不可用：自动加入离线队列，恢复后补发；
- 截图失败：不影响保存结果，可点「重试截图」。

## 四、保存后的操作

完成态提供以下按钮：

| 按钮 | 作用 |
| --- | --- |
| 在剪藏库查看 | 打开服务器 `/read/{id}` 阅读页 |
| 打开原文 | 新标签页打开原网页 |
| ☆ 收藏 / ★ 已收藏 | 切换收藏状态 |
| 标记未读 / 已读 | 切换阅读状态（打开阅读页会自动标记已读） |
| 重新抓取正文 | 重新抓取正文快照，提示是否更新与字数 |
| 删除快照 | 仅删除正文快照，卡片保留 |
| 重试截图 | 截图失败后重新截取 |
| 撤销 | 删除刚保存的卡片 |

## 五、快速保存（无弹窗）

| 入口 | 行为 |
| --- | --- |
| `Alt+Shift+S` | 快速保存当前页，使用默认分组与上次截图设置 |
| 页面右键 →「保存到 SolarPanel」 | 同上 |
| 链接右键 →「保存此链接到 SolarPanel」 | 只保存该链接，标题由服务端抓取 |
| 选中文本右键 →「保存选中文本到 SolarPanel」 | 保存当前页，并把选中文字写入备注 |

快速保存会在页面右下角弹出轻提示，工具栏图标同时显示角标：`✓` 成功、`=` 链接已存在、`…` 已入离线队列、`!` 失败。`chrome://`、`edge://` 等受限页面不支持保存。

快捷键无响应通常是和输入法 / 其他扩展冲突（如 `Alt+Shift` 切换语言），可在设置里改绑为 `Ctrl+Shift+Y` 等组合。

## 六、最近剪藏页签

弹窗第二个页签「最近剪藏」：

- 显示最近 **4 条**剪藏，含标题、分组、已读状态、是否有截图，收藏项带 `★`。
- 点击任一条目打开阅读页。
- 顶部搜索框按标题 / 正文 / 标签实时搜索（输入后自动查询）。
- 「全部 →」进入完整剪藏库（`/clips`），可继续筛选、排序与分页。

## 七、离线队列

- 网络失败（无法连接服务器）时，保存请求最多缓存 **50 条**在本机。
- 打开弹窗、浏览器启动、扩展安装 / 更新时自动重试补发。
- Token 失效、无剪藏权限、请求过于频繁、参数错误等永久性错误不会进入队列，直接提示。

## 八、错误提示对照

| 提示 | 原因与处理 |
| --- | --- |
| Token 无效或已过期（401） | 到设置更新 Token；后台可重新生成，旧 Token 会失效 |
| 账号无剪藏权限 / 站点已关闭剪藏（403） | 联系管理员开启剪藏或调整账号权限 |
| 请求过于频繁（429） | 稍后重试，避免短时间连续保存 |
| 无法连接服务器 | 检查地址、端口、反向代理与网络；内网地址需能直连 |
| 当前页面不支持保存 | 仅支持 `http` / `https` 页面，浏览器设置页、扩展页等无法保存 |
| 截取失败 | 部分页面禁止截图或过长；可改用「仅可视区」或「不截图」 |

## 九、权限与隐私

- `activeTab` + `scripting`：仅在点击、右键或快捷键时读取当前页地址 / 标题 / 选中文本，不申请「读取所有网站数据」。
- `contextMenus`、`commands`、`storage`：右键菜单、快捷键、本机配置与离线队列。
- 不注入常驻内容脚本，不加载远程代码，不收集或上报任何数据。
- Token 只存于本机 `chrome.storage.local`，仅发送到你配置的服务器。

## 十、Firefox

Firefox Release 版要求签名，未签名扩展只能在 `about:debugging` →「临时载入附加组件」，**重启浏览器后失效**。Firefox 用户建议改用书签小工具或网页快速添加。

## 十一、升级与卸载

- **升级**：下载新 zip → 解压覆盖原目录 → 在扩展管理页点「重新加载」。扩展不自动更新、不远程加载代码。
- **卸载**：在扩展管理页移除即可；本机配置与离线队列随扩展数据一并删除，服务器上的剪藏不受影响。

## 十二、常见问题

**保存后卡片没有图标或封面？**
图标与封面由服务器抓取，部分站点会拦截；可在后台编辑卡片手动上传图标。

**整页截图出现重复页头或黑线？**
扩展截图时会隐藏固定 / 吸顶元素并按页面底色填充拼接，仍有异常可改用「仅可视区」。

**阅读页打不开？**
确认服务器地址可访问、Token 有效，且后台未关闭剪藏功能。

**换电脑后要重新配置吗？**
需要。配置与 Token 保存在本机浏览器，不随账号同步。
