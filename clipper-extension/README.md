# SolarPanel 剪藏扩展（Chrome / Edge）

把当前网页一键保存为 SolarPanel 导航卡片。扩展只负责读取当前页 URL / 标题 / 选中文本，标题、图标、封面与描述统一由服务端抓取。

## 安装（zip 侧载）

1. 从 GitHub Releases 下载 `solarpanel-clipper-v1.0.0.zip`，校验同目录 `SHA256SUMS.txt`。
2. 解压到固定目录，例如 `D:\SolarPanel\clipper`（不要移动或删除）。
3. 打开 `chrome://extensions` 或 `edge://extensions`，开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择解压出的 `solarpanel-clipper` 目录。
5. 打开扩展「设置」，填写服务器地址与个人 Token（在 SolarPanel 后台「剪藏与接入」生成）。

浏览器会提示「开发者模式扩展」，这是侧载的正常现象。

## 使用

| 入口 | 行为 |
|---|---|
| 点击工具栏图标 | 打开弹窗，可改标题、分组、备注 |
| 页面右键 | 保存到 SolarPanel |
| 链接右键 | 保存此链接 |
| 选中文本右键 | 保存选中文本（作为备注） |
| `Alt+Shift+S` | 快速保存当前页，使用默认分组 |

保存成功后可在弹窗里打开原文或撤销；重复链接会提示已存在，可选择仍要另存。

## 权限说明

- `activeTab` + `scripting`：只在点击 / 右键 / 快捷键时读取当前页标题，不申请「读取所有网站数据」。
- `contextMenus`、`commands`、`storage`：右键菜单、快捷键、本机配置与离线队列。
- 不注入常驻内容脚本，不加载远程代码。

## 离线与错误

- 网络失败时最多缓存 50 条待发送记录，浏览器下次启动或打开弹窗时自动重试。
- 401：Token 失效，请到设置更新；403：账号无剪藏权限或站点关闭了剪藏；429：请求过于频繁，稍后重试。

## Firefox

Firefox Release 版要求签名，未签名扩展只能用 `about:debugging` →「临时载入附加组件」，**重启浏览器后失效**。Firefox 用户建议改用书签小工具或网页快速添加。

## 升级

下载新 zip → 解压覆盖原目录 → 在扩展管理页点「重新加载」。扩展不自动更新、不远程加载代码。

## 隐私

Token 只保存在本机 `chrome.storage.local`，仅随剪藏请求发送到你自己配置的服务器；扩展不收集、不上报任何数据。
